# 2차 최종본 — 논문·코드에 실제로 적용할 것

이번 검토에서 나온 지적을 **구현 단위 작업**으로 변환한 목록이다. 각 항목은 담당·마감·완료 조건을 포함한다.

---

## A. Overlap 측정기 (§5.3) — 담당 B, 1~2주 차

기존 계획의 "유효 edge 중앙값"은 SfM 매칭이 실패한 쌍을 빼고 계산하므로, 저텍스처·저겹침 장면일수록 겹침이 실제보다 높게 나온다. 이 값이 승패 지도의 가로축이므로 그대로 두면 경계 위치 자체가 틀어진다.

**구현 사항**

1. pairwise 계산: `O_ij = 2|P_i ∩ P_j| / (|P_i| + |P_j|)`
2. 매칭 실패 쌍·공통 point 임계 미만 쌍은 **제외하지 말고 `O_ij = 0`으로 기록**
3. 집계는 세 값을 모두 산출: 전체 쌍(0 포함) **평균**(주 지표), **하위 25% 분위수**(보조), 중앙값(참고용·주 지표로 쓰지 않음)
4. 입력 view 집합이 연결 그래프를 못 이루면(고립 view 존재) 플래그를 남기고 메인 집계에서 분리
5. 장면별 **texture 통계**(gradient energy 등)를 함께 로깅 — 겹침 효과와 텍스처 효과 분리용
6. 고/저 구간 경계는 전체 분포가 아니라 **view 수 수준 안에서** 층화하여 결정

**완료 조건:** 파일럿 5장면에서 view 수별 overlap 분포 히스토그램이 나오고, 0값 비율이 함께 보고된다.

## B. 통계 분석 파이프라인 (§5.12) — 담당 공동, 3주 차까지

같은 장면의 seed 3회는 독립 표본이 아니다. run 수를 표본 수로 쓰면 신뢰구간이 실제보다 좁게 나온다.

**구현 사항**

1. 집계 스크립트의 **기본 단위를 scene으로** 설정 (seed는 scene 내 반복 측정으로 평균)
2. **scene 단위 cluster bootstrap** 함수 구현 — 장면을 복원추출해 CI 산출
3. 보고 형식 고정: `평균 ± cluster bootstrap 95% CI` + `장면별 win rate (예: 24개 중 18개)`
4. (여유 시) scene을 random effect로 둔 mixed-effects 상호작용 검정 → 부록
5. 주 결론에 쓰는 검정에는 다중 비교 보정(Holm) 적용, 적용 범위를 논문에 명시

**완료 조건:** 파일럿 데이터로 bootstrap CI가 산출되고, seed를 표본으로 세는 경로가 코드에 남아 있지 않다.

## C. τ(승패 임계값) 정의 (§5.5) — 담당 공동, 3주 차

seed 변동성만으로 τ를 정하면 "변동성이 크게 나오면 무승부 구간이 넓어지는" 자기참조가 생긴다.

**적용:** `τ = max(파일럿 seed 간 변동성, 실용적 최소 유의 차이)`. 후자는 문헌 관행(PSNR 0.3~0.5dB 수준)을 근거로 제시한다. 두 근거를 논문에 함께 기술한다.

---

## D. C2 사전 가설 동결 (§3.1) — 담당 A, 3주 차

가설 없이 시작하면 결과를 본 뒤 설명을 붙이는 사후 분석으로 읽힌다.

**적용:** H1(초기 오차↑ → Gaussian 수↑·품질↓, low-overlap에서 강화), H2(view 수↓ → 품질 정점 시점 앞당겨짐·하강 가팔라짐), H3(초기 품질이 충분하면 refinement 이득 소멸)를 **지지/기각 판정 기준과 함께** 파일럿 전에 문서로 고정한다. 기각된 가설도 삭제하지 않고 결과와 함께 기술한다.

---

## E. Depth 개입 실험 확장 (§5.9) — 담당 A, 8~9주 차

기존 iid 곱셈 노이즈는 분석은 깨끗하지만 실제 depth 오류의 모양이 아니다. 실제 오류는 물체 경계, 텍스처 없는 면, 전역 스케일 편향에서 구조적으로 발생한다.

**구현 사항**

1. 기존 유지: `d' = d(1 + ε), ε ~ N(0, σ²)`, σ = 0 / 0.01 / 0.03 / 0.05 / 0.10
2. **추가: global scale bias** `d' = s·d`, s = 0.9 / 0.95 / 1.0 / 1.05 / 1.1 — 한 줄 구현, monocular depth의 대표 실패 모드
3. 논문 서술 수위를 **"민감도 측정"으로 제한** — "현실의 모든 depth 오류를 재현하는 것이 아니라, 초기 depth 불확실성 증가가 refinement 동역학에 미치는 민감도를 통제된 조건에서 측정한다"
4. (여유 시) spatially correlated noise 1종 추가

## F. 이전 라운드에서 확정되어 유지되는 항목

| 항목 | 내용 | 담당·시점 |

| 렌더 등가성 gate | FF Gaussian → standard 표현 변환 후 렌더 결과 일치 확인. 실패 시 C1-b 미진행 | A, 1~2주 |

## G. 논문 집필에 반영할 문장 (초안)

- **Overlap 절:** "매칭이 성립하지 않은 view 쌍을 제외하면 저텍스처·저겹침 장면에서 겹침도가 체계적으로 과대평가되므로, 본 연구는 해당 쌍을 0으로 포함하여 집계하였다."
- **통계 절:** "동일 장면에서 얻은 반복 실행은 독립 표본이 아니므로, 장면을 클러스터 단위로 하는 bootstrap으로 신뢰구간을 산출하였다."
- **개입 실험 절:** "본 개입은 실제 depth 오류를 재현하는 것이 아니라, 초기 depth 불확실성 수준에 대한 최적화 동역학의 민감도를 통제된 조건에서 측정한다."
- **한계 절:** "iid 오차와 전역 스케일 편향만을 다루었으며, 경계 및 무텍스처 영역에서 발생하는 공간 상관 오차는 후속 과제로 남긴다."

## 우선순위

**즉시(STEP 0~1):** A(overlap 측정기) → F(로깅·gate·디렉터리 분리) → B(통계 파이프라인 골격)
**파일럿 전 동결(STEP 2):** C(τ) → D(가설) → B(bootstrap 검증)
**본 실험 이후:** E(개입 확장) → G(집필 문장 반영)

A와 B는 승패 지도의 가로축과 신뢰구간을 각각 결정하므로, **둘 중 하나라도 미완인 상태로 본 실험에 진입하지 않는다.**
